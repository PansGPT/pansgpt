# Assistant-ui adoption and native streaming

User direction: remove the duplicate Steps disclosure, use assistant-ui's fluid text streaming, and prefer its existing chat components over rebuilding their behavior. Keep the approved welcome, composer geometry, palette, image layout and mobile sheet navigation.

## Contract and acceptance

- Keep `@assistant-ui/react`'s external-store runtime over authenticated FastAPI SSE. Backend ownership, branch persistence, attachment UUIDs, privacy policy and tool authorization remain authoritative. No direct client-provider calls or database migration.
- Use `MarkdownTextPrimitive` with native `smooth` and `defer`. Remove the custom word spans, reveal scheduler, receipt timestamp, HAST plugin and associated CSS. Completed short replies and loaded history render immediately, following native behavior; genuine running text reveals progressively and reduced motion renders immediately. Test intermediate visible prefixes, final text, Markdown/code/math/tables, cancellation and reload.
- Render a single model-authored activity line while waiting. Remove the Steps component and synthetic reasoning parts from the adapter. Preserve validated progress/tool metadata for history and actual-phase gating; do not display private reasoning or erase backend records. Artifacts, sources and errors remain visible independently of Steps.
- Native feedback buttons dispatch through the existing backend adapter. Display only server-confirmed rating state, disable pending submissions, and retain visible error/retry behavior. Native local message export contains the selected message's public text, never hidden branch content, tool arguments or reasoning.
- Native clipboard paste and attachment dropzone feed the same private attachment adapter as the picker; validate supported MIME/size before upload, require Send before inference, preserve ordinary text paste and report rejected files. Sending still requires a caption and at most four attachments.

Assistant-ui supplies UI behavior; our adapter still connects account authorization, tenant isolation, durable history, retrieval, credits, private storage and backend tools. Prefer native primitives or Elements for future chat work, customize theme/layout, and add feature-specific adapters where required. Do not treat every optional feature as ready merely because the library exports it.

Inspected the installed `@assistant-ui/react` **0.15.30** and `@assistant-ui/react-markdown` **0.14.23**, including smooth text, feedback, attachment events/dropzone and export implementations, against the official [Markdown](https://www.assistant-ui.com/docs/ui/markdown), [ActionBar](https://www.assistant-ui.com/docs/primitives/action-bar) and [Thread Elements](https://www.assistant-ui.com/elements/thread) documentation. The first native attachment check caught a missing event subscription: unsupported MIME types are rejected by the composer before our adapter runs. Subscribe to native add/error events so picker, paste and drop all show one visible error and clear it on success.
