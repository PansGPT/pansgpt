## Tavily public-query exception - 25 October 2026

- **Authority:** The user selected “Allow a Tavily retention exception for public searches” after being told that queries may be retained and shared with search-index providers. The user also explicitly authorized obtaining the Tavily key from the legacy backend. Only this key was copied into the ignored local API environment; no runtime legacy imports or committed credentials were added.
- **Scope:** Minimal public standalone queries through `POST https://api.tavily.com/search`. No uploaded file content, full conversation histories or patient details. Explicit private document/attachment turns do not inherit public eligibility. Known identifier/credential patterns are rejected before cache/quota/network dispatch. These controls are conservative restrictions, not a certified personal-data anonymizer.
- **Terms:** [Tavily privacy policy](https://www.tavily.com/privacy) describes retention and possible sharing with search-index providers. Account-specific ZDR is not established. `provider_privacy_allowed("tavily")` and `TAVILY_ZDR_CONFIRMED` remain false; the search engine separately checks the public-only exception.
- **Configuration:** `TAVILY_PUBLIC_SEARCH_ALLOWED=false` by default and in committed templates; true only in the ignored local environment for the current credential. Private/non-public queries still require the strict gate. Hosted rollout needs its own settings, disclosure and verification.
- **Account readback:** `GET /usage` accepted the local credential and reported Researcher plan, 1,000 included credits, zero used at the initial check. This checks key/account availability and free allocation, not retention. Basic searches only; no advanced-depth or paid-model escalation. Live verification used public queries without student persistence.

## Google retention exception - 22 October 2026

- **Authority:** The user explicitly requested: "remove it for gemino", after being told that free Gemini content may be retained, human-reviewed and used for product improvement. This is a provider-specific policy change, not verified ZDR or a change to Google's service.
- **Scope:** Existing Google AI Studio inference paths: Gemma generation, Gemini classification/expansion, vision and 1536-dimensional embeddings. The source policy applies across environments; no hosted deployment or secret changes were performed. Other providers retain their attestation gates.
- **Disclosure:** Under [Google's unpaid-service terms](https://ai.google.dev/gemini-api/terms), submitted content and responses may be used to improve products and reviewed by humans. Confidential, sensitive or personal information must not be sent to unpaid services. Paid no-training terms do not alone establish ZDR; [Google's ZDR guide](https://ai.google.dev/gemini-api/docs/zdr) describes continued abuse-monitoring logging and directs guaranteed-ZDR workloads to Vertex AI.
- **Implementation:** `Settings.provider_privacy_allowed()` allows only Google without attestation. Provider adapters, readiness and ingestion producer/outbox use that policy. The legacy `GOOGLE_ZDR_CONFIRMED` field remains false/ignored for environment compatibility; examples no longer suggest that Google needs an attestation. API-only routing, credentials, feature flags, authorization, quotas and safety controls remain required.
- **Verification:** Ruff formatting/lint passed. The targeted offline suite passed **80 tests** (one live embedding test skipped; two existing dependency deprecation warnings): provider adapters/privacy, embeddings, ingestion producer/outbox, readiness, model deadlines and isolated worker verification guards. Mocked Google generation and embeddings work with the legacy ZDR flag false; unverified other providers remain blocked, and missing Google keys still prevent ready status. No live inference, hosted deployment or application-job processing was performed. Operators must restart API/workers to load the changed code.

The earlier screenshot showed the pre-change disabled state; no enabled-state screenshot was supplied.
- **Credential/account scope:** Only the organisation associated with `GROQ_API_KEY` in ignored `apps/api/.env`. No key is recorded here. The organisation ID and billing tier were not supplied; this attestation must not be copied to another credential, staging, CI or production. The documented ZDR control is available to all customers. Obtain an explicit organisation identifier and fresh settings evidence before hosted activation.
- **Endpoint scope:** Generation, expansion and vision use `/openai/v1/chat/completions`; Groq transcription uses `/openai/v1/audio/transcriptions`. Both are listed as ZDR eligible in [Groq's data policy](https://console.groq.com/docs/your-data). This does not approve batch, fine-tuning, built-in hosted tools or new endpoints.
- **Retention:** Global ZDR opts out of reliability/abuse prompt and response retention and disables persistence-dependent features. Usage metadata remains. The policy includes applicable-law retention qualifications; this is not a promise that legal obligations can be overridden.
- **Training:** [Services Agreement](https://console.groq.com/docs/legal/services-agreement), section 4.2, restricts training on inputs/outputs unless the customer explicitly permits it. No training permission is granted by this local configuration.
- **Configuration:** Set only local `GROQ_ZDR_CONFIRMED=true`; keep code defaults false and all other provider attestations false. Restart the API to load the changed environment. Revoke the local flag if Global ZDR is disabled or the credential's organisation changes.
- **Verification (before the subsequent Google exception):** A fresh Python process loaded the local environment and confirmed Groq eligible, with Google, OpenRouter, OpenAI, Tavily and Cohere blocked. The existing privacy, failover, deadline and usage regression selection passed: **21 tests**, with two existing dependency deprecation warnings. These tests block service network access. No live inference or hosted deployment was performed. Git confirms `apps/api/.env` remains ignored.
